# Camping Mod 2 - GPLv3 Fix

This is a GPLv3 fork of The Camping Mod 2, originally created by Rikmuld for Minecraft 1.12.2.

The original mod has been discontinued and has the following issue:
- When keepInventory is enabled, camping backpack GUI items disappear on player death

This fork fixes the issue above and improves related logic during the fix.

Fixes:
- Fixed camping backpack items disappearing on death when keepInventory is enabled
- Fixed an item duplication bug caused by GUI data not being cleared after death when keepInventory is disabled (discovered and fixed during the repair process)

All original assets (textures, models, sounds, etc.) belong to their original authors and are used under GPLv3 as distributed with the original mod.
Code fixes are GPLv3 by liuzhihao.
